## Limite și verificări următoare

- Exportul pe pagină + interogare nu a fost încă obținut. Prin urmare, nu afirmăm canibalizare sau poziții pe query pentru fiecare URL fără această probă.
- Indexarea se verifică în raportul de pagini și prin inspecția URL, nu prin absența din tabelul de performanță.
- Nu schimbăm automat title-urile tuturor celor 47 de pagini; prioritățile sunt homepage, RCA, calculator RCA și produsele cu multe afișări și CTR redus.
